# Explicit Agent Backends and Disposable Review Workspaces

**Status: accepted.** The first multi-agent phase retains the existing OpenCode Serve backend and adds explicitly selected Codex CLI, Claude CLI, and Pi CLI backends; it does not introduce automatic routing or fan-out. Each Review Job reads an operator-maintained `repo_roots` mapping whose keys may be a project-group prefix or a complete project URL. It uses the longest path-boundary match, tries the derived local path first, then recursively searches that local root up to a configured Discovery Depth and accepts only a Git repository whose remote origin matches the Source Repository. At execution time it fetches both the latest Source Revision and the latest Target Revision from their respective projects rather than pinning the webhook event SHA or trusting a fork-local target branch, then reviews from their merge base. It creates a disposable Review Worktree under a configured Worktree Parent for review and optional auto-fix; the Agent chooses child paths, branch names and other Git details, while cleanup remains mandatory. If no local repository matches, it clones into a configured Clone Workspace parent; Review Worktrees are always removed and clone retention defaults to deletion but remains configurable. All backends use one Shared Review Skill, which is also the canonical backend prompt and is referenced by path; backend-specific invocation wrappers contain no duplicated review policy. Agent-owned delivery uses already-authenticated platform CLIs such as `glab` and `gh`, not MCP; CLI authentication is explicitly outside this project's responsibility. Agent-owned delivery and the current auto-fix default are retained to keep the external service thin, and the prompt should specify only these necessary boundaries while leaving tactical details to the Agent.

The initial configuration defaults are `discovery_max_depth: 3`, `clone_parent: data/agent-clones`, `clone_cleanup: always`, `worktree_parent: data/agent-worktrees`, and `shared_review_skill: skills/review-agent/SKILL.md`; the shared skill path may be overridden by environment configuration.
